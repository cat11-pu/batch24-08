# GSB Bugfix Task
## 题面
登录限流现在永远放行：同一 IP 和账号可以无限试，X-Forwarded-For 也不处理。rate_guard.py 是核心，tests/test_rate_guard.py 15 个红。要修成按 IP+账号做滑动窗口限流，超过阈值拒绝，窗口和阈值参数要校验，代理头只在可信代理时采信，空 IP/账号和非法时间要明确报错。修完 15 个测试后，还要保证 1000 组随机 IP/账号/时间没有绕过，32 线程并发尝试最多只放行限额；不许改测试或写死计数。边界至少覆盖 0 限额、负窗口、空 IP、空账号、可信/不可信代理头。

## 运行方式
```bash
python -m pytest tests -q
```
